# 👕 PrintArt — Site d’impression sur Hoodies & T-Shirts

## 🖋️ Description du projet

**Mochtara** est une application web développée avec **Laravel** permettant aux utilisateurs de **personnaliser leurs hoodies et t-shirts** en y ajoutant des **logos, textes ou designs uniques**.  
Le site propose une expérience simple et fluide pour visualiser les produits avant commande et gérer le processus de personnalisation.

---

## 🚀 Fonctionnalités principales

- 🎨 **Personnalisation des produits** : ajout de logos, textes et images sur les modèles (hoodies, t-shirts).  
- 🖼️ **Aperçu en direct** du design avant validation.  
- 🛒 **Système de panier et de commande**.  
- 👩‍💻 **Espace administrateur** pour gérer les produits, les designs et les commandes.  
- 💬 **Formulaire de contact** pour les demandes clients.  
- 🔐 **Authentification et gestion des utilisateurs** (clients & admin).

---

## 🏗️ Technologies utilisées

- **Backend** : [Laravel] (https://laravel.com/)  
- **Frontend** : Blade Templates, HTML5, CSS3, JavaScript  
- **Base de données** : MySQL  
- **Outils de design** : Figma (pour la maquette UI/UX)  
- **Versioning** : Git & GitHub
